# Présentations des jeux

Sources publiques consultées le 28 octobre 2026 :

- Profil : https://hakhan-laf.itch.io/
- Shadow Project.exe : https://timoyo.itch.io/shadow-exe
- Dig! Dig!! Dig!!! : https://go-for-rune.itch.io/dig-dig-dig
- Bloody Mary : https://go-for-rune.itch.io/bloody-mary
- Jiangshi Tactics : https://go-for-rune.itch.io/jiangshi-tactics

Chaque jeu possède une page HTML locale dans projets/. Les descriptions sont reformulées en français et les visuels proviennent des pages publiques. Les crédits collectifs sont conservés. Seule la page de Jiangshi Tactics détaille les tâches d’Adrien L : game design et programmation. Les autres contributions personnelles restent à préciser avec Adrien.

Aucun jeu, lecteur externe ni module de téléchargement n’est embarqué. Les boutons ouvrent les pages itch.io dans un nouvel onglet. Les captures sont hébergées avec le portfolio.

Les résumés des cartes se modifient dans content.js. Les pages détaillées sont les fichiers HTML de projets/ ; les modifier également si les informations changent. Aucune synchronisation automatique n’est configurée.

# Jeux intégrés au portfolio

Pages publiques consultées le 28 octobre 2026 :

- Profil de l’utilisateur : https://hakhan-laf.itch.io/
- Shadow Project.exe : https://timoyo.itch.io/shadow-exe
- Dig! Dig!! Dig!!! : https://go-for-rune.itch.io/dig-dig-dig
- Bloody Mary : https://go-for-rune.itch.io/bloody-mary
- Jiangshi Tactics : https://go-for-rune.itch.io/jiangshi-tactics

Les visuels et captures proviennent de ces pages. Les descriptions sont reformulées en français à partir des descriptions publiques. Les crédits collectifs sont conservés. Seule la page Jiangshi Tactics détaille les tâches d’Adrien L : game design et programmation. Les autres contributions personnelles restent à préciser avec Adrien.

Les trois lecteurs navigateur utilisent les adresses de jeu effectivement présentes dans les iframes des pages itch.io. Ils sont chargés uniquement quand le visiteur ouvre « Jouer sur cette page ». Fermer le lecteur ou filtrer vers un autre domaine le décharge. Ces jeux se jouent au clavier ; la présentation est responsive, sans supposer une prise en charge tactile.

Jiangshi Tactics est un jeu Windows : son widget officiel itch.io permet d’amorcer le téléchargement. Aucun exécutable n’est copié ni lancé par le portfolio. Le widget peut ouvrir le parcours de téléchargement itch.io.

Documentation : https://itch.io/docs/creators/widget et https://itch.io/docs/creators/html5

Pour mettre à jour les jeux, modifier les objets dans `content.js`. Les champs `embed.upload` proviennent des URL d’iframe publiées par itch.io ; vérifier ces adresses après une nouvelle version du jeu. Les mises à jour du profil itch.io ne sont pas synchronisées automatiquement.

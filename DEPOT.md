# Dépôt de travail autorisé

Seul dépôt autorisé pour ce portfolio : https://github.com/Hakhanlaf/Lafontaine-Portfolio

Adresse GitHub Pages prévue : https://hakhanlaf.github.io/Lafontaine-Portfolio/

Conserver la direction artistique avec les barres bleues et orange. Les teintes actuelles sont ajustables dans `styles.css`, variables `--blue` et `--orange` ; leur correspondance exacte avec la DA d’origine reste à confirmer à partir d’une référence visuelle.

Le site est à la racine : `index.html`. Le contenu se personnalise dans `content.js`. Les champs vides ne doivent pas être remplacés par des informations inventées.

Pour publier ce dépôt, importer les fichiers à sa racine puis configurer **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Le dépôt existe déjà : inutile d’en créer un autre. Voir `GUIDE-PUBLICATION.md` pour les conseils de personnalisation et les vérifications.
